# Medidor de Anel IA

Protótipo web para estimar o aro de anel usando a câmera do celular, um cartão padrão como referência de escala e visão computacional.

## Primeira fase

- Acesso à câmera traseira
- Guia para posicionar cartão e dedo no mesmo plano
- Captura e confirmação da fotografia
- Base preparada para calibração com OpenCV.js

## Executar

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite. Para testar a câmera em outro aparelho, publique em HTTPS.
